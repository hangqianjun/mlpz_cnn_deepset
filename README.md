Functions and notes for the CNNPZ estimator

- `cnnpz_utils.py` contains functions to transform input catalogue and train emsemble models
- `CNN_photoz-ensemble-cardinal.ipynb` contains the tests done with the up-to-date model on the Cardinal dataset compiled in `make_train_test_data.ipynb`
- `CNN_photoz-ensemble-bpz-31-temp.ipynb` contains tests of the model on mock photometry generated by 31 templates from BPZ
- `CNN_photoz-ensemble-cardinal_with_i_mag.ipynb` experiments adding i-band magnitude information into the sensitivity curve (doesn't seem to work that well)
- `CNN_photoz-ensemble-pz_challenge_t1/t2.ipyn` running model on the actual data challenge datasets, including pre-training on popcosmos mock for t2.
